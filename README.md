# 🖐️ GestureX

Real-time hand landmark detection and gesture tracking system built using Python and MediaPipe. Designed for touchless interaction, gaming control, and accessibility applications.

---

## 🚀 Features
- **Real-Time 3D Hand Tracking:** Utilizes MediaPipe Tasks Vision API for high-accuracy 21-point hand landmark detection.
- **Low Latency Performance:** Optimized for real-time webcam video feeds.
- **Fast Dependency Management:** Powered by `uv` for instant environment setup and package synchronization.

---

## 🛠️ Tech Stack
- **Language:** Python
- **Computer Vision & AI:** MediaPipe, OpenCV
- **Package Manager:** `uv`
